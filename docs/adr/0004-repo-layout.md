# 0004. Монорепозиторий без корневых workspaces
- Статус: принято
- Дата: 2026-09-16
- Автор: Команда

## Контекст
Сервисы написаны на разных языках и развиваются параллельно. Общий корневой `package-lock.json` (npm workspaces) меняется при любом `npm install` в любом сервисе и постоянно даёт конфликты слияния.

## Решение
- Один репозиторий, сервисы в `services/<name>/`, каждый со своим менеджером пакетов и lock-файлом.
- Корневого `package.json` нет. `contracts/` — отдельный маленький npm-пакет с линтером и моком.

## Последствия
- Нет общих dev-скриптов на корне — команды описаны в `docs/guides/dev-setup.md` и README сервисов.
- CI запускает джобы по сервисам независимо.
