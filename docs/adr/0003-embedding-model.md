# 0003. Модель эмбеддингов: paraphrase-multilingual-MiniLM-L12-v2
- Статус: принято
- Дата: 2026-09-16
- Автор: Команда

## Контекст
ТЗ (REQ-STK-08) называет Sentence-BERT `all-MiniLM-L6-v2` «или её совместимые аналоги». `all-MiniLM-L6-v2` обучена на английских данных и плохо работает с русским текстом документации.

## Решение
Используем `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` — то же семейство MiniLM/Sentence-BERT, размерность 384 (как у all-MiniLM-L6-v2), поддерживает русский. Запасной вариант — `cointegrated/rubert-tiny2` (быстрее, 312-мерная). Имя модели — в конфиге (`EMBEDDING_MODEL`), модель фиксируется в `model_version`.

## Последствия
- Эмбеддинги совместимы по размерности с исходной моделью.
- Скорость ниже L6 примерно в 2 раза; при необходимости — кеш эмбеддингов якорей и батчинг, цель ≤ 500 мс на параметр.
