# Примеры выходных данных

Настоящие выгрузки api с живого прогона 24.09 — не написаны руками. Источник — проверка
[`scripts/stand-offline-check.sh`](../../scripts/stand-offline-check.sh): образы api, ml и мок
«РиН» во внутренней сети без интернета, на входе контрольный комплект
[`scripts/demo-errors-set.py`](../../scripts/demo-errors-set.py) (ПД + РД + ИД, объект вымышлен,
ошибки внесены заранее), один акт ИД подан сканом — значение из него взято распознаванием.

| Файл | Формат | Что это |
|---|---|---|
| [submission.sample.json](submission.sample.json) | `GET /api/v1/protocols/{id}/export?format=submission` | Ответ участника по `submission_schema.json` организаторов: одна запись на контрольную точку, значения ПД / РД / ИД, метка нарушения, страницы доказательств |
| [gold.sample.json](gold.sample.json) | `…/export?format=gold` | Выгрузка по листу «СХЕМА GOLD» Приложения 1: эталонное и фактическое значение, файл, SHA-256, шифр, редакция, страница и рамка доказательства по каждой стадии, полнота комплекта |

Что внутри. Активны все 132 параметра матрицы (с 24.09), поэтому в `submission`
107 записей — по каждой применимой контрольной точке:

- `VIOLATION_PRESENT` — три: M-002 «Общая площадь здания» (12 480,6 → 11 905,3 м², −4,61 %),
  M-055 «Фундаментная плита» (B30 → B25 в РД и ИД), M-055 «Плиты перекрытия» (B25 → B22,5 в ИД);
- `NO_VIOLATION` — две: M-001 «Площадь застройки» (1 420,5 = 1 420,5) и M-055 «Вертикальные
  конструкции» (B35 = B35);
- `COMPARISON_IMPOSSIBLE` — 102: значения параметра в этом маленьком комплекте нет.
  Неприменимые по реестру параметры (разделов нет в комплекте) в выгрузку не попадают.

В `gold` — пять записей: точки, где сравнение состоялось.

Протокол не финализирован (`IN_PROGRESS`): это выход машины до решения инспектора. Модель
не ставит `CONFIRMED_VIOLATION` (REQ-CMP-05) — подтверждает нарушение только инспектор.

Воспроизвести: `./start.sh` (собрать образы), затем `./scripts/stand-offline-check.sh` —
свежие выгрузки лягут в `var/offline-check/`. Идентификаторы и время при каждом прогоне свои.
